# ქონების გადასახადის დეკლარაცია (ფორმა V-01) — მომხმარებლის ტესტირების სახელმძღვანელო

ეს დოკუმენტი ნაბიჯ-ნაბიჯ აღწერს, როგორ შეამოწმოს მომხმარებელმა მოდული `gec_property_tax_report`
მთლიანად: კლასიფიკატორები, აქტივების აღრიცხვა, დეკლარაციის გენერაცია, ხელით შეყვანილი სტრიქონები,
ექსპორტი, მიწა და ცვეთის გააქტიურება.

**სად ტარდება ტესტირება:** მხოლოდ სატესტო ბაზაში (მაგ. `gec_test`), არასოდეს — სამუშაო ბაზაში.

**როგორ შეავსოთ:** ყოველ ტესტს აქვს ნომერი (მაგ. `T-04.2`). შეასრულეთ ნაბიჯები, შეადარეთ შედეგი
„მოსალოდნელ შედეგს“ და ჩაწერეთ ბოლოს მოცემულ ცხრილში: ✅ გავიდა / ❌ არ გავიდა + შენიშვნა.
თუ შედეგი არ ემთხვევა, გადაიღეთ ეკრანის სურათი და ჩაწერეთ, რა ნახეთ.

თანხები მოცემულია ლარში. სადაც წერია „დაახლოებით“, მცირე სხვაობა (რამდენიმე თეთრი) ნორმალურია.
